Security Architecture

Every layer is designed so that even if one part is compromised, the others hold.

1
Webhook

Signature Verification — HMAC-SHA256

Every request GitHub sends to your server is signed with a secret only you and GitHub know. Before processing anything, the server recomputes the signature and compares it using a timing-safe check. If it doesn't match, the request is dropped with a 401 — no exceptions.

GitHub signs → X-Hub-Signature-256: sha256=abc123...
Server recomputes HMAC with your secret
Mismatch → 401 Unauthorized, request ignored
2
Tokens

Short-Lived Access Tokens — 1 Hour Expiry

The server never stores a permanent GitHub token. Each time it needs to read a PR diff, it requests a fresh token using the app's private key. That token expires in 60 minutes — even if intercepted, an attacker gets nothing useful.

App private key → requests installation token
GitHub issues → token valid 60 minutes only
Token expires → next request gets a new one
3
Storage

Encrypted Slack Credentials at Rest

The Slack bot token is never stored in plain text. It is encrypted before being saved to the database and decrypted only at the moment it's needed. If someone dumps the database, they get ciphertext — not a working token.

Slack token → encrypted → saved to DB
On PR event → decrypted in memory → used → discarded
DB breach → attacker gets encrypted blob only
4
Access

Scoped Repository Access

When a user installs the GitHub App, they explicitly choose which repositories to grant access to. The app can only ever see those specific repos — nothing else in the organization or account is accessible, even by accident.

5
Design

GitHub App vs OAuth

OAuth ties the token to a person. If that person leaves, the integration breaks — and their token keeps working until manually revoked. GitHub Apps are tied to the installation, not any individual.

OAuth (user token) GitHub App
Token tied to A person The installation
Employee leaves Integration breaks Nothing changes
Token lifespan Until manually revoked 1 hour, auto-rotated
Access scope Everything the user can see Only selected repos
